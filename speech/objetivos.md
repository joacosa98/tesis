# Speech — Slide 5: Objetivos

Partiendo de esta base, los objetivos del proyecto fueron estos 3. El orden cronologica es este

Como primer paso, integrar una cámara al robot que procese imagenes. Luego, implementar un módulo de Behavior tree reutilizable para controlar las acciones del robot. Y como ultimo paso, diseñar una Actividad para niños que se pueda usar en un salon de clase, que utilice la camara integrada, y que el comportamiento del robot este implementado utilizando el BT.
